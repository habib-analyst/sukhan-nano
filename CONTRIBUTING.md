# Contributing

Issues and pull requests are welcome on GitHub.

For a bug report, include the smallest prompt or input that reproduces the
issue, the full generated output, and the Python, PyTorch, and NumPy
versions involved.

For a code change:

1. Add or update tests for the behavior you changed.
2. Run `python -m pytest -q`.
3. Keep the model card honest: any number quoted in `README.md` must be
   reproducible from the artifacts in this repository.
